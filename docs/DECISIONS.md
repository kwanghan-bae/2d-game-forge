## 2026-09-13 — AI-03A 에이전트 기억·신념·재계획

- 승인: 사용자가 LLM을 제품에서 영구 배제하고, 순수 코드 기반 AI 고도화를 승인했다.
- 결정: `meta.ai.agentBrains.<agent>.cognition`을 schema 3의 additive 확장으로 두고,
  에이전트별 bounded 기억·역할 편향 신념·다단계 계획을 보관한다. 기억은 중요도와
  감정값이 시간에 따라 감쇠하며, 신념은 실제 세계 상태와 분리해 관찰 노이즈·역할
  편향·신뢰도를 가진다.
- 행동 연결: 세계 tick마다 각 에이전트가 관찰을 갱신하고, 피로·관계·실패 기억·
  신념을 함께 평가해 계획을 유지하거나 중단·재계획한다. 사건이 보류되면 계획의
  중단 횟수를 기록하며, 작업·원정·관계 변화·결과는 다음 판단의 기억으로 남긴다.
- 저장·안전 경계: cognition의 기억·신념·계획 수는 상한을 두고, 기존 유효 schema 3
  저장은 seed 기반 기본값으로 한 번 확장한다. 같은 저장·seed·tick은 같은 관찰과
  계획을 재현하며, LLM·외부 모델·서버·네트워크를 코드·저장·핵심 판정에 추가하지
  않는다.
- 재검토: 기억 감쇠와 계획 중단이 장기 플레이에서 선택 다양성·설명 이해도·저장
  크기·Android 성능에 미치는 영향을 실기기 표본으로 측정할 때.

## 2026-09-13 — schema 3 시뮬레이션 저장 기반

- 승인: 사용자가 schema 3 확장과 장기 AI 고도화를 승인했다.
- 결정: canonical 저장 키 `shin-ui-eternal-sponsor-save-v2`는 제품 식별자이므로
  바꾸지 않고, 저장 envelope의 현재 버전을 3으로 올린다. schema 3은 필수
  `meta.ai`와 `meta.simulation`을 가진다. simulation에는 결정형 seed, 일자 tick,
  마지막 시뮬레이션 시각, bounded 세계 사건 처리 저널을 저장한다.
- 전환: canonical 슬롯의 유효한 현재 schema 2만 한 번 schema 3으로 승격한다.
  AI가 없던 schema 2도 `createdAt` 기반 기본 상태를 받아 진행을 보존한다. 잘못된
  저장은 기존처럼 원본을 보존하고 자동 덮어쓰지 않는다. 과거 제품·과거 key
  fallback은 추가하지 않는다.
- 장기 순서: 저장/재현 계약 → 지원 에이전트별 목표·관계·스케줄러 → 에이전트별
  기억·신념·재계획 → 사건 연쇄와 세계 세력 → deterministic replay·AI 행동 다양성
  평가 순으로 확장한다. 핵심 판정은 로컬 결정형 규칙을 유지한다.
- 재검토: schema 3이 실제 출시 계약이 되는 시점, 사건 저널 상한과 migration
  실패율, 장기 플레이에서의 저장 크기와 복구 가능성을 측정할 때.

## 2026-09-13 — 지원 에이전트 AI-02

- 승인: 사용자가 schema 3 확장에 이어 장기 AI 고도화를 계속 진행하도록 승인했다.
- 결정: `meta.ai.agentBrains`를 schema 3의 additive 확장으로 두고, 대장장이·무당·
  길잡이마다 목표·목표 진행도·긴장도·동료 간 directed 관계·다음 일정과 판단
  이유를 결정형으로 보관한다. 기존 schema 3에서 이 필드가 없는 유효 저장은
  seed와 현재 world tick으로 한 번 기본 brain을 채운다.
- 행동 연결: 세계 tick마다 scheduler가 각 에이전트의 피로·영웅 신뢰·동료 관계·
  날씨·전문 역할을 utility로 재평가한다. 자동 영웅 원정은 휴식 우선 길잡이를
  억지로 배정하지 않고, 원정 forecast와 마을 화면은 선택된 계획과 이유를
  설명한다. 사건에서 여러 동료가 같은 결정을 겪으면 관계와 긴장도가 함께
  변한다. 명시적 플레이어 작업을 AI가 가로채거나 자동 확정하지 않는다.
- 재검토: 지원 에이전트의 계획 다양성, 관계 변화가 실제 선택에 미치는 영향,
  계획 설명 이해도, 장시간 저장 크기와 실기기 성능을 측정할 때.

## 2026-09-13 — 결정형 영웅 AI와 원인 기반 마을 사건 1차

- 근거: 기존 영웅 자율 행동은 HP·정책 중심의 고정 분기였고, 사가는 완료 결과를
  기록할 뿐 진행 중인 세계 사건이나 기억을 표현하지 않았다. 제품의 단일 영웅과
  소수 지원 에이전트 루프를 유지하면서 행동의 납득 가능성과 세계의 연속성을
  높일 필요가 있다.
- 결정: Utility AI가 성격·욕구·최근 기억·정책·날씨·전투 준비도를 평가한다.
  `meta.ai`에 결정형 seed, bounded memory, 영웅 욕구, 세계 날짜·계절·날씨·영역
  위협도, 미해결 사건을 저장한다. 사건은 원인·선택·결과·사가·기억의 흐름을
  가지며, 미해결 사건이 있으면 자동 행동은 플레이어 선택까지 대기한다. 선택
  기한을 넘기면 사건을 놓친 기억·사가를 남기고 큐에서 제거한다.
- 저장 경계(당시 1차): 현재 schema 2를 깨지 않는 optional additive 상태로
  적용했다. 이후 schema 3 시뮬레이션 저장 기반 결정으로 승격했다.
- 안전 경계: 보스·영역 해금·서사 선택의 자동 확정 금지, 15초 유예, 동일 seed
  재현성, 오프라인 중복 정산 방지를 유지한다. 외부 서비스·서버·LLM은 제품 범위에서
  사용하지 않는다.
- 재검토: AI 행동 다양성·사건 선택 완료율·플레이어가 이유를 이해하는지에 대한
  신규 사용자 및 실기기 표본이 생길 때.

## 2026-09-08 — 실행 제어 추가 승인

- 근거: 문서 정리 진행 중 사용자가 자동 실행 제어도 요청했다. 완료 후 루나에게 “자율작업 시작해”라고 요청하여 장기 개발하는 것이 목표다.
- 결정: 외부 의존성 없는 로컬 상태/lease 제어기와 명령 취소 wrapper를 추가한다. 기본 paused, 명시적 승인 시 새 generation, 단일 writer, 중단 시 이전 generation 무효화, 현재 작업까지만 종료를 지원한다. 초기 문서 전용 범위를 이 제어 구현까지 확장한다.
- 경계: 실제 게임 개발·예약 활성화·commit/push는 이번에 하지 않는다. OS 전체 작업 차단이나 계정 한도 우회 기능은 아니다. 장기 자동 호출은 향후 시작 시 제품 예약 도구로 연결한다.
- 재검토: 루나의 첫 실제 장기 실행에서 예약·중단·재개 E2E를 관찰한 뒤. 현재 로컬 제어 테스트와 구분한다.

## 2026-09-08 — 출시 준비 보강 범위 승인

- 근거: 감사에서 정책이 읽기 전용 예측에 머무르고, 표시 승률·시설 설명·서사·계측·CI가 제품 약속과 어긋난 것이 확인됐다. 사용자는 제안한 보강 순서를 실행하도록 승인했다.
- 결정: canonical Village save는 schema 2다. 자율 행동은 단일 전이로 유지하며,
  공유 원정 forecast, 사가·신뢰도를 이용한 깊은 숲 선택과 저승 에필로그,
  별도 로컬 계측, 게임 build/E2E CI를 구현한다. 이후 출시 전 현재 제품만
  유지하기로 결정하여 schema 2의 현재 형태만 읽는다.
- 자율 행동 경계: 플레이어 입력을 위한 15초 유예를 두고 한 번에 행동 하나만 시작한다. 미확인 결과·위험 보스·Realm 해금·서사 선택은 자동 처리하지 않는다.
- 문서 정리: 추적된 root status, 계획·스펙·보고서·archive·persona·agent 파일은 현재 트리에서 제거하고 Git 이력으로 보존한다. 살아 있는 제품·운영·라이선스 사실은 canonical docs에 통합한다.
- 권한: 이 보강 커밋은 허용한다. push·merge·예약 활성화·무한 자율 반복은 허용 범위가 아니다.

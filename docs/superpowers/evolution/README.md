# 자율 진화 산출물

이 디렉토리는 자율진화 루프의 cycle 별 산출물이다.

## 파일 이름 규칙

- `cycle-N-critic.md` — 게임비평가 평가 (A1 단계)
- `cycle-N-story-critic.md` — 스토리작가 평가 (A2 단계)
- `cycle-N-level-critic.md` — 레벨디자이너 평가 (A3 단계)
- `cycle-N-research.md` — 웹리서치 (B1 단계, 조건부)
- `cycle-N-prd.md` — 게임기획자 PRD (C 단계)
- `cycle-N-test-plan.md` — QA 테스트 계획 (D1 단계)
- `cycle-N-ui-guide.md` — UI/UX 가이드 (D2 단계)
- `cycle-N-assets.md` — 무료 에셋 조사 (D3 단계)
- `cycle-N-result.md` — F 단계 직후의 병합 SHA와 검증 결과

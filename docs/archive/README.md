# 기록 보관 안내

과거 기록은 현재 운영에 필요한 최소 항목만 기본 트리에 남기고, 나머지는 Git 이력에서 찾는다. 보관 문서는 현재 실행 권한을 부여하지 않는다.

| 분류 | 처리 | 읽는 경우 |
|---|---|---|
| `docs/PRODUCT.md`, `OPERATIONS.md`, `작업-현황.md`, `BACKLOG.md`, `DECISIONS.md` | 현재 기준 5개 | 매 작업에 필요한 부분만 |
| 2026-09-06 V4 상세 GDD | 유지 | 기능 상세·경제 목표 확인 |
| 2026-09-06 V4 출시 준비 계획 | 현재 승인 범위 | 작업별 합격 조건·검증 확인 |
| `docs/superpowers/evolution/RESUME.md`, `cycle-156-assets.md` | 실행 중단 안내·라이선스 근거 | 필요한 경우만 |
| `autonomous-evolution-v4/v5/v6/v7.md` | 대체된 운영안, 제자리 보관 | 과거 실패 원인 조사 |
| `docs/personas/` | 과거 역할 참고 | 현재 역할 계약에 필요한 기법만 참조 |
| 그 외 specs/plans/reports | 필요 시 참조, 자동 실행 금지 | 관련 기능의 원래 의도 확인 |
| ARCHITECTURE/CONTRIBUTING/CREDITS/privacy-policy | 전문 문서 유지 | 공용 구조·자산·출시 작업 |

2026-09-08 감사에서 evolution 파일 461개가 검색 문맥을 오염시키는 것을 확인했다. 현재 운영과 라이선스 근거에 필요한 2개만 남기고 459개는 현재 트리에서 제거하며, 상세 이력은 Git에서 찾는다. 미완료 과거 계획도 현재 승인 없이는 백로그로 승격하지 않는다.

대체한 README 현황·CLAUDE 브리핑·작업 현황·RESUME의 원문만 이 디렉터리에 별도 보존했다. 보관본의 상대 링크는 명시된 원래 경로 기준이며 새 운영 문서 링크로 사용하지 않는다. `file://` 등 과거 링크까지 일괄 수리하지 않는다.

신규 cycle별 보고서·역할 대화록·만점 평가를 만들지 않는다. 상태는 한 곳에 갱신하고 상세 증거는 Git·CI·테스트 산출물에서 찾는다.

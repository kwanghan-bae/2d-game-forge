## 이번 정리

현재 게임의 단일 부팅 경로와 package·route·Android 식별자를 정리하고, 사용하지
않는 구형 실행 트리·도구·에셋·의존성을 제거했다. 저장 boundary는 canonical
key 하나와 현재 schema 3 형태를 사용하며, 즉시 이전의 유효한 schema 2만 명시된
1회 migration으로 승격한다. 과거 제품·과거 key·임의의 이전 저장 형태는 자동
보정하지 않는다. 포털은 현재 게임 하나만 등록한다.

추가 승인 범위에서는 영웅의 성격·욕구·기억을 Utility AI 입력으로 만들고, 게임 내
날씨·계절·마을 사정·동료 상태에서 결정형 세계 사건을 생성했다. 사건 선택은
자원·신뢰·영역 위협도·사가·영웅 기억에 반영되며, 미해결 사건 동안 자동 행동은
대기한다. 선택 기한을 넘긴 사건은 놓친 기억·사가로 남기고 큐에서 제거한다.
`meta.ai`는 schema 3에서 필수 상태가 되었고, `meta.simulation`이 tick·마지막
시각·bounded 사건 처리 저널을 함께 보관한다. 기존 schema 2에는 `createdAt`
기반 결정형 기본값을 넣어 한 번 승격한다.

이어서 지원 에이전트마다 목표·목표 진행도·긴장도·동료 관계·다음 일정을 가진
`agentBrains`를 schema 3에 additive로 확장했다. 세계 tick마다 피로·영웅 신뢰·
관계·날씨·전문 역할을 재평가하며, 자동 원정은 휴식 우선 길잡이를 배정하지
않는다. 원정 forecast와 Town Hub에서 계획과 이유를 확인할 수 있고, 여러 동료가
같은 사건 선택에 참여하면 관계 변화도 bounded 상태로 기록한다.

AI-03A에서는 각 지원 에이전트의 `cognition`에 bounded 경험 기억·역할별 편향이 있는
신념·다단계 계획을 추가했다. 실제 세계 상태와 에이전트가 인식한 상태를 분리하고,
세계 tick마다 관찰을 seed 기반으로 재현한다. 피로·실패 기억·신념·보류 사건에 따라
계획을 유지하거나 중단·재계획하며, 작업·원정·관계 결과가 다음 계획과 기억에
반영된다. Town Hub에는 목표뿐 아니라 현재 계획 단계도 표시한다. LLM·외부 모델·
서버·네트워크는 제품 범위에서 영구 제외한다.

AI-03B에서는 기존 날씨·사회·물자·징조 사건을 각기 다른 원인 연쇄의 시작점으로
연결했다. `meta.ai.world.factions`에 마을·상인·정령의 신뢰·영향력·긴장도를
bounded 값으로 보관하고, 선택·만료 결과는 연쇄 momentum과 세력 상태를 갱신한다.
후속 사건은 최대 2단계까지 deterministic하게 예약되며, 같은 날 여러 연쇄가
겹치면 세력 영향력과 예약일로 우선순위를 정한다. `parentEventId`·chain step·
faction은 event history에도 기록하고, 기존 schema 3 저장에는 기본 세력·빈 연쇄를
한 번 채운다. 이 확장도 LLM·외부 모델·서버·네트워크 없이 로컬 규칙으로만
판정한다.

AI-03C에서는 영웅 자율행동과 지원 에이전트의 선택을 `simulation.decisionHistory`에

canonical replay fingerprint와 섹션별 mismatch를 만들고, 결정 종류·에이전트
목표·사건 선택·사건 타입의 다양성을 0..1 점수로 계산한다. 기존 schema 3 저장에는
빈 journal을 한 번 채우며, 평가 결과는 자동 튜닝이나 외부 전송 없이 로컬 검증에만
사용한다. LLM·외부 모델·서버·네트워크는 계속 제외한다.

AI-03D에서는 세계 세력 상태를 지원 에이전트의 부분 관찰로 연결했다. cognition에
세력별 `faction_trust`·`faction_tension` 신념을 추가하고, 대장장이·무당·길잡이가
각각 상단·정령·마을을 주 담당 축으로 읽게 했다. 신뢰·긴장도와 진행 중 연쇄·영향력은

seed 기반 기본값으로 한 번 보정하고, LLM·외부 모델·서버·네트워크 없이 로컬 규칙으로
판정한다.

AI-03E에서는 장기 행동을 실제 플레이 런타임과 분리해 검증할 수 있도록
`runVillageAIScenario`를 추가했다. 초기 저장 또는 임의의 저장 복사본을 기준으로

준비 문구를 표시한다. LLM·외부 모델·서버·네트워크는 추가하지 않는다.

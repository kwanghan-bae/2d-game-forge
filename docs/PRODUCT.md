# 제품 기준서

## 제품과 핵심 경험

출시명은 **신의 마을: 영원의 후원자**다. 한국 우선, 로컬 우선의 모바일 게임이다. 영원한 영웅 한 명에게 애착을 갖고, 마을의 생산·장비·정책 선택으로 그 영웅의 성장을 돕는 균형형 하이브리드를 만든다. 정책을 정하면 15초의 개입 유예 뒤 영웅이 회복·훈련·원정 중 다음 행동 하나를 고르며, 결과 확인과 영구 진행은 플레이어가 결정한다. 이블헌터 타이쿤은 시설 생산망과 원정의 참고 대상이지 복제 대상이 아니다.

핵심 루프: 영웅 상태·병목 확인 → 시설·장비·정책 선택 → 작업·원정 진행 → 결과와 사가 확인 → 다음 선택. 구현량보다 이 연결이 실제 플레이에서 작동하는지로 평가한다.

## 출시 범위

- 영웅 1명, 지원 에이전트 3명(대장장이·무당·길잡이).
- 고정 시설 7개: 신전·회복당·대장간·훈련소·무당집·원정소·기록관. 시설별 활성 작업 1개.
- Realm 3개: 조선 평야·깊은 숲·저승. 동시 원정 1개.
- 최소 사가: 프롤로그, Realm별 진입·승리, 깊은 숲 선택 사건 1개, 저승 승리 후 첫 사가 에필로그. 이후 반복 운영은 계속한다.
- 오프라인 최대 8시간, 온라인 효율 70%. 보스·선택 사건·회춘·영구 해금은 자동 확정하지 않는다.
- 패배 시 영구 장비·재화 손실 없음. 부족한 능력치·추천 시설과 장비·재도전 예상 시간을 안내한다.
- V4 기본 진입점과 전용 저장. V3 legacy·저장 보존. 영웅 가져오기는 명시적 사용자 선택으로만 실행한다.
- 기존 Forge UI·Galmuri·Joseon pixel 자산 재사용.
- 강제 전면 광고 없음. 보상형 하루 최대 5회, 오프라인 2배·작업 완료·개입 충전에 한정. 광고·결제 실패가 진행을 막지 않는다.

서버·계정·클라우드·PvP, 지원 에이전트의 가족·사망, 20개 던전·600층·16캐릭터 확대는 이번 출시 범위가 아니다. 균열석 판매는 soft launch 근거 없이 추가하지 않는다.

## 합격 기준

- 신규 플레이어가 15분 안에 첫 원정을 시작하고, 30분 안에 시설·장비·정책 중 2개 이상을 변경할 수 있다.
- 일반 구간 3연속 패배율 5% 미만을 측정한다. 표본·시드·정책을 기록한다.
- 8시간 복귀 보상 뒤 실제로 선택 가능한 강화·장비·원정 중 다음 행동을 제공한다.
- 시설 변경이 생산·전투·원정 결과에 영향을 주는 비교 검증이 있다.
- 화면의 예상 승률과 실제 원정 판정이 같은 forecast를 사용한다.
- 저장 격리·실패 복구·모바일 조작을 검증한다. D1·D7 등 유저 지표는 실제 데이터 전까지 미측정으로 둔다.

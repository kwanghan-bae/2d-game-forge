# 제품 기준서

## 제품과 핵심 경험

**신의 마을: 영원의 후원자**는 한국 우선·로컬 우선의 모바일 게임이다.
한 명의 영웅과 마을의 시설·장비·정책을 관리하고, 영웅의 행동 결과를 확인하며
다음 선택을 이어 간다.

핵심 루프는 다음과 같다.

영웅 상태 확인 → 시설·장비·정책 선택 → 작업·원정 진행 → 결과와 사가 확인
→ 다음 선택.

Android를 우선 대상으로 하며, 웹은 같은 도메인 로직과 입력 흐름을 빠르게
검증하는 개발 표면이다.

## 출시 후보 범위

- 영웅 1명, 지원 에이전트 3명(대장장이·무당·길잡이)
- 시설 7개: 신전·회복당·대장간·훈련소·무당집·원정소·기록관
- 영역 3개: 신목 들판·깊은 숲·저승
- 영역별 일반·정예·보스 원정과 결과 확인
- 프롤로그, 영역 진입·승리 기록, 깊은 숲 선택 사건, 저승 승리 에필로그
- 오프라인 최대 8시간, 온라인 효율 70%
- 보스·선택 사건·회춘·영구 해금의 자동 확정 금지
- 패배 시 영구 장비·재화 손실 없음
- 강제 전면 광고 없음. 보상형 광고는 하루 5회 한도

서버·계정·클라우드·PvP와 대규모 캐릭터·던전 확대는 이번 범위가 아니다.

## 합격 기준

- 신규 플레이어가 15분 안에 첫 원정을 시작한다.
- 30분 안에 시설·장비·정책 중 두 종류 이상을 변경할 수 있다.
- 시설 변경이 생산·전투·원정 결과에 반영된다.
- 화면의 예상 승률과 실제 원정 판정이 같은 forecast를 사용한다.
- 오프라인 정산은 중복 지급하지 않고, 위험한 결과는 명시적 확인을 요구한다.
- 저장 실패·복구·모바일 조작을 검증한다.
- 실제 사용자 지표와 실기기 동작은 별도 출시 검증에서 측정한다.

## 저장·배포 식별자

- canonical 저장 키: `shin-ui-eternal-sponsor-save-v2`
- 저장은 현재 schema만 읽는다. 과거 제품·과거 키로의 자동 복구나 import는 없다.
- Android `applicationId`/namespace: `com.shinui.eternalsponsor`
- 웹·포털 경로: `/games/inflation-rpg`

출시 전이므로 외부 사용자 저장 호환 계약은 존재하지 않는다. 저장 구조를
바꿀 때는 현재 제품의 테스트와 문서를 함께 갱신한다.

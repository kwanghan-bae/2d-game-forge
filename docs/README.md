# 문서 안내

현재 제품은 **신의 마을: 영원의 후원자 V4**다. 자율 개발은 기본 중단이며 실제 실행 여부는 [현재 상태](작업-현황.md)와 제어기 상태로 확인한다. 루나에게 명시적으로 시작을 요청할 때의 절차는 [운영 규칙](OPERATIONS.md)에 있다.

## 기본 읽기 순서

1. [현재 상태](작업-현황.md): 권한·기준 커밋·검증의 한계부터 확인한다.
2. [제품 기준서](PRODUCT.md): 만들 게임과 제외 범위를 확인한다.
3. [운영 규칙](OPERATIONS.md): 위임·검증·통합·중단 규칙을 확인한다.
4. [우선순위 백로그](BACKLOG.md): 승인 범위 내 다음 문제를 선택한다.
5. [결정 기록](DECISIONS.md): 중요한 선택의 이유만 필요할 때 확인한다.

## 필요할 때만 읽는 문서

- [V4 상세 GDD](superpowers/specs/2026-09-06-eternal-hero-town-tycoon-gdd-ko-design.md): 기능·경제·KPI의 상세 목표. 구현 완료 증거가 아니다.
- [V4 출시 준비 계획](superpowers/plans/2026-09-06-shin-ui-v4-implementation.md): 현재 승인 범위와 작업별 검증 계약. 완료 항목을 처음부터 다시 실행하지 않는다.
- [아키텍처](ARCHITECTURE.md), [기여 가이드](CONTRIBUTING.md): 공용 구조·새 패키지 변경 시 확인한다.
- [크레딧](CREDITS.md), [개인정보처리방침](privacy-policy/ko/index.html): 자산·출시 관련 변경 시 확인한다.
- [기록 보관 안내](archive/README.md): 과거 계획·평가·페르소나 자료의 분류와 사용 방법.

문서 전체를 매 작업마다 읽거나 과거 cycle의 다음 작업을 자동 실행하지 않는다. 현재 사용자 지시가 과거 문서보다 우선한다.

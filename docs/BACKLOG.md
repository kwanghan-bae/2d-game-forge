# 우선순위 백로그

상태: **출시 준비 보강 6개 작업 중**. 실행 범위는 [현재 계획](superpowers/plans/2026-09-06-shin-ui-v4-implementation.md)과 제어기의 현재 generation으로 제한한다. 완료 뒤 자동 반복·push·예약 실행은 하지 않는다.

| ID / 우선순위 | 해결할 문제 | 합격 조건 | 현재 증거·상태 |
|---|---|---|---|
| OPS-01 / P0 | 중단 뒤 자동 재개 방지 | 로컬 제어 검증 + 실제 루나/예약 중단·재개 E2E. 오래된 예약이 start하지 않음 | 로컬 generation·lease·관리 명령 취소 구현과 회귀 테스트 완료. 앱 예약·별도 에이전트 E2E는 재개 후 확인 필요 |
| QA-01 / P0 | CI와 제품 검증 범위 차이 | 게임 V4+legacy E2E·build 및 동일 SHA 통합 게이트의 실제 실행 증거 | `.github/workflows/ci.yml` E2E는 dev-shell 대상. 게임 전용 게이트 점검 필요 |
| GAME-01 / P1 | 신규 첫 30분 루프 입증 | 신규 저장→첫 전투→시설→장비→원정. 15분 첫 원정, 30분 내 2종 선택 변경. 병목과 소요시간 기록 | 기존 테스트 존재와 제품 목표 충족을 분리해 재검증 필요 |
| GAME-02 / P1 | 선택이 결과에 미치는 효과 | 시설/장비/정책별 대조 실행, 영웅 판단이 실제 행동으로 연결되는지 확인 | V4 runtime·domain·화면 연결 감사 필요 |
| GAME-03 / P1 | 복귀와 패배 이후 선택 | 8시간 정산 중복 없음, 보스 자동 확정 없음, 보상 뒤 가능한 선택. 패배 원인/추천/재도전 시간 표시 | offline·원정 테스트를 실제 플레이 흐름과 대응 필요 |
| DATA-01 / P1 | 목표 지표 측정 부재 확인 | 주요 로컬 이벤트·지표 계산·표본 정의 검증. D1/D7 미측정 명시 | GDD 이벤트 요구 존재. V4 일부 이벤트명 검색에서 발견 못함; 전체 구현 감사 필요 |
| DEVICE-01 / P2 | 실기기 출시 검증 | iOS/Android 조작·복귀·광고 실패·결제 취소/복원/환불 결과 | 장비·계정 필요. 브라우저 에뮬레이션으로 대체 불가 |

작업을 선택할 때만 담당·허용 파일·가설·재현 명령·예산을 해당 항목에 덧붙인다. 범위 밖 콘텐츠 확장은 출시 병목보다 먼저 선택하지 않는다. 각 항목은 검증됨/반려/차단/미측정으로 끝내며 테스트 존재만으로 완료하지 않는다.
